# ShopZone E-Commerce Website 🛒

A modern and responsive E-Commerce Website developed using HTML, CSS, JavaScript, Selenium WebDriver, and TestNG.

This project includes an interactive Login Page, Product Section, Cart Functionality, Contact Form, and Logout System.

---

# 🚀 Features

- Professional Login Page
- Responsive E-Commerce UI
- Add to Cart Functionality
- Cart Counter Update
- Smooth Scroll Navigation
- Contact Form Alert
- Logout Functionality
- Interactive JavaScript Actions
- Selenium Automation Testing
- TestNG Integration
